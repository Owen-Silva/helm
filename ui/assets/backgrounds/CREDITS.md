# Background credits

These are Helm's bundled default backgrounds. `wallpaper.png` in this folder is
a local dev copy (gitignored) and is not one of the defaults.

Every photo is from Unsplash under the Unsplash License (free photos only, no
Unsplash+). Full images are 2560px wide JPEGs (<= 600 KB), re-encoded by the
Unsplash image CDN or, where the CDN file was over 600 KB, re-encoded locally.
`thumbs/` holds a 400px-wide JPEG of each one. `catalog.json` lists them all
(file, title, category, credit, url) for the Settings gallery.

The first three (forest, lake, stone) were downloaded on 2026-10-07; the rest
on 2026-10-08.
